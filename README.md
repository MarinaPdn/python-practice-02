Консольный калькулятор

Назначение
Простое консольное приложение на Python для выполнения арифметических действий. Программа выводит все сообщения розовым цветом.

Решаемые задачи
- Приём двух чисел и оператора от пользователя.
- Поддержка операций: +, -, *, /, //, % (остаток), ^ (возведение в степень).
- Проверка корректности ввода (числа, допустимые операции).
- Обработка деления на ноль.
- Возможность выхода в любой момент через ввод 'm'.

Запуск
1. Установите Python 3.6 или выше.
2. Скачайте файл "1. консольный калькулятор.py" в любую папку.
3. Откройте терминал (командную строку) в этой папке.
4. Выполните команду:
```bash
   python "1. консольный калькулятор.py"
   ```

Использование
- После запуска следуйте подсказкам на экране.
- Вводите числа (можно дробные, разделитель – точка).
- Вводите оператор из списка.
- Для выхода введите 'm' вместо любого запрашиваемого значения.

Пример работы
Добро пожаловать в консольный калькулятор!
Доступные операции: +  -  *  /  //  %  ^ (степень)
Для выхода введите 'm' в любом поле.

Введите первое число (или 'm' для выхода): 15
Введите операцию (+, -, *, /, //, %, ^): *
Введите второе число (или 'm' для выхода): 4
Результат: 60.0

Введите первое число (или 'm' для выхода): 10
Введите операцию (+, -, *, /, //, %, ^): /
Введите второе число (или 'm' для выхода): 0
Ошибка: Деление на ноль!

Введите первое число (или 'm' для выхода): m
До свидания!

Настройка цвета
По умолчанию используется розовый цвет. Если цвета отображаются некорректно (видны странные символы), откройте файл "консольный калькулятор.py" и замените в нём строки:
PINK = "\033[38;5;205m"
RESET = "\033[m"
на
PINK = ""
RESET = ""
— это отключит цвета, но калькулятор продолжит работать.
